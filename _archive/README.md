# The Model Verse — Repository Archive (`_archive/`)

This directory contains experimental, research, and legacy subsystems that are preserved for reference and history but decoupled from the active 2D Manim automated YouTube Shorts production pipeline.

## Contents

- **`aether/`**: Project Aether 3D cinematic world model, multi-agent council, compiler, and repair engine. Preserved from feature development.
- **`project-aether-docs/`**: Design specifications, architecture blueprints, and WBS deliverables for Project Aether.
- **`pipeline/`**:
  - `aether_director.py`: Legacy pipeline wrapper for Project Aether autonomous director.
  - `schemas.py`: Pre-VSG video specification schema.
  - `svg_synthesizer.py`: Legacy on-the-fly SVG generator (superseded by Visual Engine 6.0 Bespoke Visual Synthesizer).
- **`test/`**:
  - Test suites for Project Aether modules and legacy components.
